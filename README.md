# Домашнее задание к работе 6

## Условие задачи

Разработать программу, которая запрашивает у пользователя целое число от 1 до 99 (обозначающее количество копеек) и выводит его вместе со словом «копейка» в требуемой падежной форме. Примеры: 5 копеек, 41 копейка и т. д.

## 1. Алгоритм и блок-схема

### Алгоритм решения

  1. **НАЧАЛО**
  2. Считать с клавиатуры целое число n (1 ≤ n ≤ 99).
  3. Определить число, по которому выбирается форма слова:
     * если остаток от деления n на 100 больше 20, то key = n mod 10;
     * в противном случае key = n mod 100.
  4. По значению key вывести нужное окончание:
     * key = 1 → «n копейка»;
     * key ∈ {2, 3, 4} → «n копейки»;
     * во всех остальных случаях → «n копеек».
  5. **КОНЕЦ**
